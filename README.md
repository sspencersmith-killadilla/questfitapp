# Story Fit

is it possible to create a fitness tracker that connects to apple watch and withings scale and uses AI generated narrative fitness challenges to encourage health and fitness? Like a serialized novel that unlocks and changes depending on your activity level?

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://questfitapp.lovable.app

## Build with Lovable
